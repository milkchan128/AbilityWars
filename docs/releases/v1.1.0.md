# AbilityWars v1.1.0

시작 배너와 자동 업데이트 기능을 추가한 버전입니다. 서버 지원 범위는 Paper·Purpur 1.21.11입니다.

출시일: 2026-10-15 (KST)

## 변경 사항

- Purpur 1.21.11 지원을 추가했습니다. 배포 JAR는 Paper와 Purpur의 1.21.11만 허용하며, Purpur에서도 기존 Paper 전용 능력과 게임을 사용할 수 있습니다.
- mlkc-devhub의 현재 로고인 우유 물방울·고리·별을 ASCII 배너로 옮겼습니다. 로고 원본은 devhub의 `frontend/public/logo.webp`이며 콘솔에는 `Powered by mlkc-studio`와 현재 플러그인 버전도 표시합니다.
- 로딩 시 `milkchan128/AbilityWars`의 최신 정식 릴리스를 비동기로 확인합니다. `v1.1.0` 형태의 태그를 숫자로 비교하며 프리릴리스와 이전 버전은 설치하지 않습니다.
- `AbilityWar-<버전>.jar`와 `SHA256SUMS.txt`를 이름으로 선택하고 SHA-256, 파일 크기, 플러그인 이름·버전 및 Paper·Purpur 1.21.11 호환 정보를 검증합니다.
- 검증이 통과하면 현재 JAR를 `plugins/AbilityWar/backups/AbilityWar-<현재 버전>.jar`에 백업하고 새 JAR를 서버의 업데이트 폴더(기본 `plugins/update`)에 기존 파일명으로 준비합니다.
- 업데이트는 다음 서버 시작 때 적용됩니다. 실행 중인 JAR를 교체하거나 서버를 자동 재시작하지 않습니다. 실패하면 현재 버전과 이미 준비된 업데이트를 유지합니다.
- `/aw install`의 버전 목록과 설치 경로도 이 포크로 변경했습니다. 새 정식 버전만 다음 서버 시작에 적용합니다.

## 설치 및 실행

1. JDK 21 환경에서 `.\gradlew.bat clean build`를 실행합니다.
2. 서버를 중지하고 기존 AbilityWar JAR를 백업한 뒤 `build/libs/AbilityWar-1.1.0.jar`를 서버의 `plugins` 폴더에 넣습니다. AbilityWar JAR는 하나만 두세요.
3. Java 21 환경에서 Paper 또는 Purpur 1.21.11 서버를 시작합니다.

```powershell
java "-Dfile.encoding=UTF-8" "-Duser.timezone=Asia/Seoul" -Xms1G -Xmx2G -jar purpur-1.21.11-2568.jar --nogui
```

서버 JAR 이름은 실제 파일명으로 바꾸세요. `-plain.jar`와 서버를 자동 종료하는 `AbilityWar-PaperSmoke.jar`는 운영 서버에 설치하지 마세요.

## 검증 결과 — 2026-10-15 (KST)

- JDK 21에서 빌드와 자동 테스트 13개가 통과했습니다. 버전 비교, 체크섬 오류, 호환되지 않는 JAR, 잘못된 배포 주소, 불완전한 다운로드, 네트워크 실패 및 기존 업데이트 보존을 확인했습니다.
- 공개된 GitHub `v1.0.0` 릴리스를 격리된 폴더로 실제 다운로드하고 SHA-256 검증 및 업데이트 준비를 확인했습니다.
- 새 릴리스 응답을 로컬에서 재현해 실제 `1.1.0` 배포 JAR를 준비한 뒤 Paper 1.21.11 빌드 132와 Purpur 1.21.11 빌드 2568을 시작했습니다. 두 서버 모두 기존 JAR를 백업하고 업데이트 폴더의 JAR를 적용해 `1.1.0`으로 로딩했습니다.
- 두 서버에서 ASCII 배너, 한글 로그, 비동기 릴리스 확인, 일반 능력 70개의 생성·정리 및 은신 장비·개인 홀로그램 패킷 검증이 통과했습니다.
- 검증 후 두 테스트 서버를 종료했습니다.

## 주의사항

- 첫 설치는 수동으로 진행해야 합니다. 자동 업데이트 기능이 없는 기존 `1.0.0`은 새 버전을 자동으로 받지 못합니다.
- 자동 업데이트는 GitHub에 배포 JAR와 체크섬이 있는 새 정식 릴리스가 공개되면 동작합니다. 첨부된 `SHA256SUMS.txt`로 배포 JAR의 무결성을 확인할 수 있습니다.
- 복구하려면 서버를 중지한 뒤 대기 중인 업데이트를 제거하고 백업 JAR로 교체하세요.
- 외부 애드온과 모든 능력의 실전 플레이는 별도 확인이 필요합니다.
