# AbilityWars v1.0.0

**Paper 1.21.11 전용 첫 정식 릴리스**입니다. 포크의 버전은 원본 AbilityWar와 별도로 `1.0.0`부터 시작합니다.

## 실행 환경

- 서버: Paper 1.21.11
- 권장 실행 환경: Java 21
- 설치 파일: `AbilityWar-1.0.0.jar`
- 지원 제외: 다른 1.21.x 버전, Spigot, Folia, 26.x

## 주요 변경 사항

- 버전 판별과 서버 내부 코드 접근을 Paper 1.21.11에 맞췄습니다.
- 가짜 플레이어, 갈고리, 홀로그램, 피해 처리 및 각종 엔티티 패킷을 포팅했습니다.
- 광대와 헤르밋의 은신 장비 숨김·복구 처리를 구현했습니다.
- Bukkit 속성·효과·인챈트·소리 이름과 파티클 데이터 형식 변경에 대응했습니다.
- 흡수 체력 설정, 가짜 플레이어 생존 확인 및 선택적인 Essentials 연동을 보완했습니다.

세부 변경 이력: [패치 노트](https://github.com/milkchan128/AbilityWars/blob/v1.0.0/CHANGELOG.md)

## 설치 방법

1. 서버를 중지하고 월드, 설정 및 기존 AbilityWar JAR를 백업합니다.
2. 기존 AbilityWar JAR를 제거한 뒤 `AbilityWar-1.0.0.jar`를 서버의 `plugins` 폴더에 넣습니다. AbilityWar JAR는 하나만 두세요.
3. Java 21 환경에서 Paper 1.21.11 서버를 시작하고 플러그인 활성화 로그를 확인합니다.

PowerShell에서 서버 폴더를 연 뒤 아래 명령을 사용할 수 있습니다. Paper 파일명은 실제 내려받은 파일명으로 바꾸세요.

```powershell
java "-Dfile.encoding=UTF-8" "-Duser.timezone=Asia/Seoul" -Xms1G -Xmx2G -jar paper-1.21.11-132.jar --nogui
```

`AbilityWar-PaperSmoke.jar`는 서버를 자동 종료하는 검증용 플러그인이므로 운영 서버에 설치하지 마세요. 릴리스에는 배포용 JAR만 첨부합니다.

## 검증 범위

- JDK 21에서 배포 JAR를 새로 빌드하고 버전 제한 자동 테스트를 실행했습니다.
- 버전 번호 변경 전 동일한 기능 코드로 Paper 1.21.11 빌드 132의 플러그인 로딩, 일반 능력 70개의 생성·정리 및 주요 호환 기능을 확인했습니다.
- 같은 서버에서 두 테스트 클라이언트로 은신 장비 숨김·복구, 투명 상태 해제, 개인 홀로그램의 표시·변경·삭제 패킷을 확인했습니다.
- 모든 능력의 실전 플레이, 외부 애드온 및 구버전 Maven 빌드는 이번 릴리스에서 검증하지 않았습니다.

## 업데이트 및 파일 검증

- 인게임 업데이트 기능은 원본 프로젝트의 릴리스를 받습니다. 이 포크는 GitHub Releases에서 받은 JAR를 수동으로 교체해 업데이트하세요.
- 첨부된 `SHA256SUMS.txt`로 JAR 무결성을 확인할 수 있습니다. PowerShell에서는 `Get-FileHash .\AbilityWar-1.0.0.jar -Algorithm SHA256`를 실행해 비교하세요.
- 이후 일반 수정은 `1.0.1`, 기능 추가는 `1.1.0`, 호환성이 깨지는 변경은 `2.0.0`처럼 버전을 올립니다.
