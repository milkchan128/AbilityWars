# AbilityWars v1.0.1 (미발행)

Paper와 Purpur 1.21.11만 지원하는 호환 보완 버전입니다. 기존 `v1.0.0` 릴리스는 수정하지 않습니다.

## 변경 사항

- Purpur 1.21.11에서 Paper 호환 모듈을 사용할 수 있습니다.
- Paper 전용 능력과 게임이 Purpur에서도 등록되도록 기존 서버 분류를 재사용합니다.
- Paper·Purpur 이외의 서버와 1.21.11 이외의 Minecraft 버전은 지원하지 않습니다.

## 설치 및 빌드

1. JDK 21 환경에서 프로젝트 루트의 `.\gradlew.bat clean build`를 실행합니다.
2. 서버를 중지하고 기존 AbilityWar JAR를 백업한 뒤 `build/libs/AbilityWar-1.0.1.jar`를 서버의 `plugins` 폴더에 넣습니다. AbilityWar JAR는 하나만 두세요.
3. Paper 또는 Purpur 1.21.11 서버를 시작합니다. `-plain.jar`와 서버를 자동 종료하는 `AbilityWar-PaperSmoke.jar`는 운영 서버에 설치하지 마세요.

서버 폴더에서 다음 명령을 사용할 수 있습니다. 서버 JAR 이름은 실제 파일명으로 바꾸세요.

```powershell
java "-Dfile.encoding=UTF-8" "-Duser.timezone=Asia/Seoul" -Xms1G -Xmx2G -jar purpur-1.21.11-2568.jar --nogui
```

## 검증 결과 — 2026-10-15 (KST)

- JDK 21에서 `clean build smokeJar` 빌드와 자동 테스트가 통과했습니다. 서버 이름 허용 목록과 1.21.11 버전 제한을 확인했습니다.
- Paper 1.21.11 빌드 132와 Purpur 1.21.11 빌드 2568에서 동일한 배포 JAR의 로딩, 일반 능력 70개의 생성·정리 및 주요 서버 호환 기능을 확인했습니다.
- 두 서버 모두에서 Paper 전용 능력인 소드 마스터의 등록을 확인했습니다.
- 두 테스트 클라이언트로 은신·해제 시 장비 숨김·복구와 개인 홀로그램의 표시 대상, 문구 변경 및 제거 패킷을 확인했습니다.
- 한글 소스·문서와 실제 서버 로그의 UTF-8 표시를 확인했으며, 검증 후 두 테스트 서버를 종료했습니다.

## 주의사항

- 외부 애드온과 모든 능력의 실전 플레이는 별도 확인이 필요합니다.
- 인게임 업데이트 기능은 원본 프로젝트의 릴리스를 받으므로 이 포크는 JAR를 수동으로 교체해 업데이트하세요.
- 이 문서는 릴리스 노트 초안이며 GitHub 정식 릴리스는 아직 발행하지 않았습니다.
